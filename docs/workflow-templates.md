# 工作流模板

工作流模板是版本化的本地 JSON 文件，用于在 Agent Studio 实例之间复制当前草稿图。模板只创建新的未发布工作流，不覆盖现有数据。

## 导出当前草稿

1. 打开工作流画布。
2. 等待工具栏显示“已保存”。
3. 点击“导出模板”，保存“工作流地址标识.workflow.json”。

导出前系统会等待保存队列完成，并校验当前草稿 revision。下载内容经过规范化，相同的工作流名称、说明和图会产生稳定的 JSON。

## 导入本地模板

1. 在工作流列表点击“导入模板”。
2. 选择不超过 2 MiB 的 `.json` 文件。
3. 审查开始参数、节点精确版本和 capability。
4. 设置新的名称、Agent 地址标识和说明，点击“导入并打开”。

兼容性预览不会写入数据库。只有预览有效，且最终导入时重新校验仍然有效，系统才会创建 revision 1 的未发布草稿。

## 安全边界

- 模板包含节点配置和自由文本，请勿把密钥写入提示词、文档或普通配置字段。
- 环境变量值、Webhook Token、运行记录和发布历史不会导出。
- 缺失节点或已知明文凭据会阻止导入；系统不会自动下载节点代码。
- 节点按 `type@typeVersion` 精确匹配，不会静默升级或降级。
- 当前只支持本地 JSON 文件，不支持 URL 导入、远程市场或 Git 同步。
