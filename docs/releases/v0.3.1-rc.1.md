# Agent Studio v0.3.1-rc.1

> 本候选版本用于验证 `v0.3.1` 发布恢复链路，不是生产稳定版，也不提供 v1 兼容承诺。本说明不表示远端 Tag 或 GitHub Release 已存在。

## 修复内容

- 标签工作流把 `GORELEASER_CURRENT_TAG` 精确绑定到触发工作流的 `github.ref_name`。即使同一提交关联多个 Tag，归档、SBOM 和校验和也必须使用当前触发 Tag 的版本名。
- Go Node SDK 补丁版本更新为 `0.3.1`，源码开发运行时显示 `0.3.1-dev`；Node API 继续为 `agent-studio.dev/v1alpha1`。
- 发布契约明确区分正式 Tag 构建与手工 dry-run，快照构建不会继承正式 Tag 覆盖。

本版本不新增 Agent、画布或节点能力，也不包含本地 RAG。功能范围与安全边界继承自已通过验证的 `v0.3.0-rc.3`。

## 发布与审计边界

失败的 `v0.3.0` Tag 保留为不可移动的审计记录，不删除、不移动、不复用，也不为其手工创建 Release。只有本标签工作流完成四平台制品、SBOM、checksum、原生 Smoke、远端资产和 immutable 状态复核后，`v0.3.1-rc.1` 才能以 `draft=false`、`prerelease=true` 公开。

候选版本通过后仍需单独批准 `v0.3.1` GA；候选版本成功不构成 GA 授权。

## 安装与验证

仅在远端 Tag 和 Pre-release 真实存在后安装：

```bash
CGO_ENABLED=0 go install github.com/yyl1212/agent-studio/cmd/agent-studio@v0.3.1-rc.1
agent-studio version
```

预编译附件覆盖 Linux/macOS 的 amd64、arm64。每个归档必须具有对应 SPDX JSON SBOM，Release 还必须包含 `checksums.txt`。下载后按附件中的 SHA-256 校验归档；macOS 二进制仍未签名和公证。

## 已知限制与安全报告

- 保持单租户、本地部署，不包含登录、RBAC、团队协作或审计后台。
- 工作流仍为 DAG，不支持循环、人工审批、定时触发或分布式队列。
- 不提供 Windows 二进制、安装器、容器镜像、代码签名或 macOS 公证。
- 不包含工具调用、多模型降级、联网搜索、文件上传或本地 RAG。

请通过 [SECURITY.md](../../SECURITY.md) 的私密渠道报告安全问题，不要在公开 Issue 中包含漏洞细节或密钥。
