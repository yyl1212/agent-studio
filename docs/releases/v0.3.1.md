# Agent Studio v0.3.1

> 这是正式开发者预览补丁版，不是生产稳定版，也不提供 v1 兼容承诺。本说明不预先宣称远端 Tag 或 GitHub Release 已存在。

## 版本与修复范围

Agent Studio Runtime 为 `v0.3.1`，Go Node SDK 为 `0.3.1`，Node API 保持 `agent-studio.dev/v1alpha1`。本补丁版继承 `v0.3.0-rc.3` 已验证的工作流模板、节点包、官方节点索引和 LLM v2 能力，不新增产品功能，也不包含本地 RAG。

发布链路现在把 GoReleaser 当前版本精确绑定到触发工作流的 Tag，避免同一提交存在多个 Tag 时生成错误版本名的归档和 SBOM。正式 Tag 构建与手工 dry-run 保持隔离。

失败的 `v0.3.0` Tag 保留为不可变审计记录，不删除、不移动、不复用，也不为其手工创建 Release。只有 `v0.3.1-rc.1` 完成四平台、源码安装、制品集合和 immutable 验证，并再次获得 GA 授权后，才可创建 `v0.3.1` Tag。

若正式标签工作流全部成功，GitHub Release 应以 `draft=false`、`prerelease=false` 公开并标记 Latest；在此之前，本文不表示该远端状态已存在。

## 安装与制品验证

仅在远端 Tag 可用后安装：

```bash
CGO_ENABLED=0 go install github.com/yyl1212/agent-studio/cmd/agent-studio@v0.3.1
agent-studio version
```

公开 Release 应提供 Linux/macOS 的 amd64、arm64 归档、四份对应 SPDX JSON SBOM 和 `checksums.txt`。下载者应核对 SHA-256；该校验只确认附件字节一致，不能代替发布者签名。macOS 二进制仍未签名和公证。

## 升级、回滚与限制

从 `v0.3.0-rc.3` 升级不需要数据库迁移。升级前仍应备份数据库和本地模板；回滚时部署此前已验证版本并恢复相应备份，不得移动或覆盖任何已发布 Tag/Release。

- 单租户、本地部署；没有登录、RBAC、团队协作或审计后台。
- 工作流仅支持 DAG；没有循环、人工审批、定时触发或分布式队列。
- 不提供 Windows 二进制、安装器、容器镜像、代码签名或 macOS 公证。
- 不包含工具调用、多模型降级、联网搜索、文件上传或本地 RAG。

请通过 [SECURITY.md](../../SECURITY.md) 的私密渠道报告安全问题，勿在公开 Issue 中披露漏洞细节或密钥。
