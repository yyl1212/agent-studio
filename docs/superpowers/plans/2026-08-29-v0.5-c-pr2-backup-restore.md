# Agent Studio v0.5-C PR2 Backup Restore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 PR1 的受信归档和维护锁基础上，交付真实目标 dry-run、兼容判断、空实例保护及单事务完整恢复。

**Architecture:** `OpenArchive` 先完成容器和 checksum 验证，`stageReferences` 把最小 ID/引用写入 PostgreSQL 临时表并执行全局语义校验；`DryRun` 持独占维护锁但回滚所有临时数据；`Restore` 在同一独占锁内迁移空 schema，再按外键顺序流式导入六张业务表，任何失败回滚全部业务数据。

**Tech Stack:** Go 1.26.0、pgx/v5、PostgreSQL 临时表与事务、PR1 `internal/database`/`internal/backup`。

**Spec:** `docs/superpowers/specs/2026-08-29-v0.5-c-instance-backup-restore-design.md`

## Global Constraints

- 本计划只在 PR1 已合并后，从最新 `origin/main` 新建 `codex/v0.5-c-backup-restore` 分支实施。
- restore 只接受 `agent-studio.dev/backup/v1alpha1` 和当前 Runtime 明确支持的旧迁移版本；禁止降级恢复。
- dry-run 不创建持久表、不写 `schema_migrations`、不写业务数据。
- 正式恢复必须持独占维护锁，必须提供 `--confirm-empty-instance`，且目标全部业务表为空。
- 允许正式恢复先把空 schema 迁移到当前版本；业务数据必须在一个事务中提交，失败时最多留下空 schema。
- 不禁用外键、CHECK、触发器或 `session_replication_role`；不自动续跑活动运行。
- 所有记录通过 PR1 显式 record 类型解码；不使用宽松 map 或 API domain struct。
- CLI/日志不输出连接串、工作流配置、运行输入输出或底层 pgx 错误正文。
- Go 测试使用 `CGO_ENABLED=0`，集成测试使用 Docker PostgreSQL 的隔离 schema。

- [ ] **Step 5: Implement lease-retaining preflight**

func DryRun(ctx context.Context, pool *pgxpool.Pool, path string) (RestorePlan, error) {
    archive, err := OpenArchive(ctx, path)
    if err != nil { return RestorePlan{}, err }
    defer archive.Close()

    lease, err := database.TryExclusive(ctx, pool)
    if errors.Is(err, database.ErrMaintenanceBusy) {

    if err != nil { return RestorePlan{}, Wrap(CodeRestoreFailed, "acquire maintenance lease", err) }
    defer lease.Release(context.Background())
    return preflightWithLease(ctx, pool, archive)
}

- [ ] **Step 4: Implement the restore orchestration with no race window**

```go
type RestoreResult struct {
    Summary          Summary               `json:"archive"`
    MigrationVersion int64                 `json:"databaseMigrationVersion"`
    Tables           map[TableName]uint64  `json:"tables"`
}

func Restore(ctx context.Context, pool *pgxpool.Pool, path string) (RestoreResult, error) {
    return restoreWithHooks(ctx, pool, path, restoreHooks{})
}

func restoreWithHooks(ctx context.Context, pool *pgxpool.Pool, path string, hooks restoreHooks) (RestoreResult, error) {
    archive, err := OpenArchive(ctx, path)
    if err != nil { return RestoreResult{}, err }
    defer archive.Close()

    lease, err := database.TryExclusive(ctx, pool)
    if errors.Is(err, database.ErrMaintenanceBusy) {
        return RestoreResult{}, Wrap(CodeAPIRunning, "target is in use", err)
    }
    if err != nil { return RestoreResult{}, Wrap(CodeRestoreFailed, "acquire maintenance lease", err) }
    defer lease.Release(context.Background())

    plan, err := preflightWithLease(ctx, pool, archive)
    if err != nil { return RestoreResult{}, err }
    if hooks.afterPreflight != nil {
        if err := hooks.afterPreflight(); err != nil { return RestoreResult{}, err }
    }
    if err := lease.Migrate(ctx); err != nil {
        return RestoreResult{}, Wrap(CodeRestoreFailed, "migrate empty target", err)
    }
    if empty, err := targetIsEmpty(ctx, pool); err != nil || !empty {
        return RestoreResult{}, Wrap(CodeTargetNotEmpty, "target changed before restore", err)
    }
    return restoreTransaction(ctx, pool, archive, plan, hooks)
}
```

Re-run empty-target validation after migration and immediately before `Begin`; do not release the lease between preflight and commit. `restoreTransaction` must consume the already verified `*Archive` and must never reopen `path`.
