# Agent Studio v0.5-C PR3 Backup Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已经可用的备份恢复内核接入 Docker 黄金路径、Makefile、中文文档、CI 和 Release 制品验证，完成 v0.5-C 交付收口。

**Architecture:** Go 端到端测试在同一个 Docker PostgreSQL 中创建相互隔离的 source/target schema，真实执行 create → inspect → dry-run → restore → 领域对比；Shell 只负责安全设置环境和调用测试。CI 使用 PostgreSQL 18 service 运行相同目标，Release 验证确认归档内 CLI 暴露备份命令。

**Tech Stack:** Go 1.26.0、Docker Compose、PostgreSQL 18、POSIX shell、GitHub Actions、现有 GoReleaser/Syft Release 验证链。

**Spec:** `docs/superpowers/specs/2026-08-29-v0.5-c-instance-backup-restore-design.md`

## Global Constraints

- 本计划只在 PR2 合并后，从最新 `origin/main` 新建 `codex/v0.5-c-backup-delivery` 分支实施。
- E2E 只能创建和删除自己的随机 schema，不得清空默认数据库、删除 Docker volume 或使用 `docker compose down -v`。
- Makefile 正式恢复必须要求 `CONFIRM=empty-instance`；不能用快捷目标绕过 CLI `--confirm-empty-instance`。
- 文档必须明确：备份含敏感运行数据、文件不加密、旧 API 必须人工停止、恢复仅限空实例、活动运行不续跑。
- CI 和文档检查必须无真实用户数据、Token、连接串密码或远端存储依赖。
- Release 附件仍只包含二进制、README、LICENSE、checksum 和 SBOM；不把黄金备份 fixture 打入发布附件。
- 不修改前端、OpenAPI、数据库迁移、节点 SDK 或 v0.5 版本号；发布版本收口属于后续阶段。
- 所有 Go 命令使用 `CGO_ENABLED=0`；所有代码完成后必须独立审查并进行完整回归。

func TestBackupRestoreE2E(t *testing.T) {
    if os.Getenv("BACKUP_E2E") != "1" { t.Skip("BACKUP_E2E is not enabled") }
    databaseURL := os.Getenv("TEST_DATABASE_URL")

    source, target := openE2ESchemas(t, databaseURL)
    seedCompleteBackupFixture(t, source)
    archivePath := filepath.Join(t.TempDir(), "instance.asbak")

    created, err := Create(context.Background(), source, CreateOptions{Output: archivePath, RuntimeVersion: "0.5.0-e2e"})
    if err != nil { t.Fatal(err) }
    inspected, err := Inspect(context.Background(), archivePath)
    if err != nil { t.Fatal(err) }
    plan, err := DryRun(context.Background(), target, archivePath)
    if err != nil { t.Fatal(err) }
    restored, err := Restore(context.Background(), target, archivePath)
    if err != nil { t.Fatal(err) }

    assertSummariesAgree(t, created, inspected, plan.Archive, restored.Summary)
    assertDomainSnapshotsEqual(t, source, target)
}

`openE2ESchemas` must serialize schema creation with the existing database test mutex or a test-only PostgreSQL advisory lock. Cleanup first requires `^backup_e2e_[0-9a-f]{24}$`, then executes `DROP SCHEMA <pgx.Identifier.Sanitize()> CASCADE`; if the guard fails, the test must fail without issuing SQL. It must never derive a cleanup identifier from archive data or an ambient schema name.
