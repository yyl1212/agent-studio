# Agent Studio v0.4-UI-A 核心工作台前端优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在不修改后端和工作流协议的前提下，交付温暖创作台视觉、单一上下文工作台、真实的节点配置提交边界和稳定画布视口。

**架构：** `StudioPage` 保留工作流数据和业务编排，新增工作台 reducer 管理互斥模式，新增配置 Hook 管理本地草稿、校验和单节点端口预解析。配置与解析端口只在用户应用时原子写入图并进入一次 SaveQueue；React Flow 保持挂载，工作台只改变容器布局。

**技术栈：** React 19、TypeScript 5.9、React Flow 12、AJV 8、Vitest、Testing Library、Playwright、CSS Custom Properties。

**规格：** `docs/superpowers/specs/2026-08-25-v0.4-ui-a-core-studio-design.md`

## 全局约束

- 所有 Go 调试、测试和生成命令显式设置 `CGO_ENABLED=0`。
- 只修改 Web、Web 测试和中文文档；不修改 Go 后端、OpenAPI、数据库、SDK 或工作流图格式。
- 不新增大型 UI 组件库、CSS 框架或全局状态库。
- 节点配置输入不得直接写入图；只有通过校验且端口解析成功的显式应用才能提交。
- 旧异步结果必须通过 AbortSignal 和 `nodeId + generation` 归属校验隔离。
- React Flow 在工作台开合时保持挂载，不再次调用 `fitView`。
- 每个行为变更先取得失败测试，再写最小实现；每个任务形成独立提交。
- UI-A 不顺带实现 UI-B 管理页面、v0.4-B 重试、本地 RAG 或 Worker。

```ts
it('只接受当前节点当前 generation 的解析结果', async () => {
  const deferred = <T,>() => {
    let resolve!: (value: T) => void
    const promise = new Promise<T>((done) => { resolve = done })
    return { promise, resolve }
  }
  const oldResult = deferred<ResolvedPorts>()
  const newResult = deferred<ResolvedPorts>()
  const signals: AbortSignal[] = []
  const resolve: ResolveNodePorts = vi.fn((_type, _version, _config, signal) => {
    signals.push(signal)
    return signals.length === 1 ? oldResult.promise : newResult.promise
  })
  const makeNode = (id: string): StudioNode => ({ id, type: 'studio', position: { x: 0, y: 0 }, data: {
    nodeType: 'llm', typeVersion: '2', config: { model: '' }, ports: { inputs: [], outputs: [] }, issues: [],
  } })
  const { result, rerender } = renderHook(({ node }) => useNodeConfigDraft({ node, edges: [], resolve, debounceMs: 0 }), { initialProps: { node: makeNode('a') } })
  act(() => result.current.setDraft({ model: 'old' }))
  await waitFor(() => expect(resolve).toHaveBeenCalledTimes(1))
  rerender({ node: makeNode('b') })
  act(() => result.current.setDraft({ model: 'new' }))
  await waitFor(() => expect(resolve).toHaveBeenCalledTimes(2))
  oldResult.resolve({ inputs: [], outputs: [{ key: 'stale', title: 'Stale', type: 'string', cardinality: 'one' }] })
  await waitFor(() => expect(result.current.nodeId).toBe('b'))
  expect(result.current.preview).toBeUndefined()
  expect(signals[0].aborted).toBe(true)
})
```
