# Agent Studio v0.4.0-rc.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已合入 `main` 的 v0.4 能力收口为版本、SDK、官方节点兼容性与发布文档一致的 `v0.4.0-rc.1`，通过全量门禁后以 annotated Tag 触发并验证 GitHub Immutable Pre-release。

**Architecture:** 发布分支只收口公共版本契约、官方 manifest、快照制品名称与文档，不修改产品业务行为。已有 GitHub Release workflow 负责受测制品的 Build → 4 平台 Smoke → Draft 上传与重下载复核 → Pre-release 公开 → Immutable 校验；本计划不改变该发布语义。

**Tech Stack:** Go 1.26.5（`CGO_ENABLED=0`）、React 19 / TypeScript / pnpm 10.34.5、PostgreSQL 18 / Docker Compose、Playwright、GoReleaser 2.17.1、Syft 1.51.0、GitHub Actions / GitHub CLI。

**Spec:** `docs/superpowers/specs/2026-08-27-v0.4.0-rc.1-release-design.md`

## Global Constraints

- 目标 Tag 精确为 `v0.4.0-rc.1`；远程 Tag 和 Release 一经创建就不得移动、删除或覆盖。
- Runtime 开发版本精确为 `0.4.0-dev`，Go SDK 精确为 `0.4.0`，Node API 保持 `agent-studio.dev/v1alpha1`。
- 官方扩展节点 Runtime 区间精确为 `[v0.2.0, v0.5.0)`。
- Go 命令统一显式使用 `CGO_ENABLED=0`。
- 不新增本地 RAG、节点、产品功能、OpenAPI 字段、migration 或依赖。
- 不创建 `v0.4.0` GA Tag；GA 必须等待独立授权。
- Release Notes 和用户文档用中文编写，不声称 RC 是生产稳定版。
- 只在发布 PR 的 Critical/Important 审查项为 0、本地全量门禁和 GitHub CI 成功后合并。

      "testing"

      "github.com/yyl1212/agent-studio/internal/nodepackage"

  func TestRepositoryManifestSupportsV040Runtime(t *testing.T) {

      source := filepath.Join(root, nodepackage.Filename)
      data, err := os.ReadFile(source)
      if err != nil { t.Fatal(err) }
      manifest, err := nodepackage.Parse(source, data)
      if err != nil { t.Fatal(err) }
      if got, want := manifest.Compatibility.Runtime.MinVersion, "v0.2.0"; got != want {
          t.Fatalf("min runtime=%s want=%s", got, want)

      if got, want := manifest.Compatibility.Runtime.MaxVersionExclusive, "v0.5.0"; got != want {

      if nodepackage.HasErrors(diagnostics) { t.Fatalf("diagnostics=%+v", diagnostics) }
  }
