# Agent Studio v0.3-B 节点包元数据与兼容检查 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立一 Module 一节点包清单、构建期兼容检查、启动期原子真实性校验、模板 v1alpha2 依赖提示，以及 CLI/API/画布展示闭环。

**Architecture:** 现有 `agent-studio.nodes.yaml` 继续作为本地安装注册包列表；`internal/nodepackage` 通过离线 `go list` 定位 Module 根清单并生成安全 PackageRecord。生成代码按 Module 分组注册到临时 Registry，核对实际节点集合后一次性提交；模板和 HTTP 只消费已经验证的安全包摘要。

**Tech Stack:** Go 1.26.5、`golang.org/x/mod`、`encoding/json`、`jsonschema/v6`、React 19、TypeScript、Vitest、Playwright Chromium、OpenAPI 3.1、Docker PostgreSQL 18。

**Spec:** `docs/superpowers/specs/2026-08-19-v0.3-node-packages-design.md`

## Global Constraints

- 实施前获取最新 `origin/main`；实现分支必须以最新 main 为祖先，并保留已确认的 spec 和本计划。
- Go 命令统一设置 `CGO_ENABLED=0`。
- 节点包探测只允许 `GOPROXY=off` 和 `go list -mod=readonly -json`；不得调用 `go get`、`go mod tidy` 或修改 `go.mod/go.sum`。
- 节点包清单固定为 Module 根目录 `agent-studio.node-package.json`，最大 256 KiB、最多 128 个 registrations、最多 512 个节点。
- Node Package 清单 apiVersion 固定 `agent-studio.dev/v1alpha1`；工作流模板新导出版本固定 `agent-studio.dev/v1alpha2`。
- 工作流模板继续接受 v1alpha1；包提示不触发下载、安装、URL 打开或 Compiler 绕过。
- Runtime 兼容范围使用 minVersion 包含、maxVersionExclusive 排除的半开区间。
- Node Definition 的 Schema、端口、capability 和运行行为始终来自实际 Go 节点，不被静态清单覆盖。
- 公开 API、模板、CLI JSON 和公开错误不得包含本地绝对路径、replace 目标、完整 `go list` 输出或凭据。
- 不新增数据库迁移、包管理页面、自动安装、远程索引、进程外插件或沙箱。
- 每个任务严格执行红灯、最小实现、绿灯、聚焦回归和独立提交。
- 使用 `apply_patch` 修改文件；保持已有用户改动，不执行破坏性 Git 操作。

`decode.go` 使用两步处理：

```go
func Decode(raw json.RawMessage) (Template, error) {
	var decoded Template
	if err := decodeStrictJSON(raw, &decoded); err != nil {
		return Template{}, err
	}
	missing, err := requiredV1Alpha1Fields(raw)
	if err != nil {
		return Template{}, err
	}
	decoded.missingRequired = missing
	return decoded, nil
}

func decodeStrictJSON(raw json.RawMessage, target any) error {
	decoder := json.NewDecoder(bytes.NewReader(raw))
	decoder.DisallowUnknownFields()
	if err := decoder.Decode(target); err != nil {
		return fmt.Errorf("decode workflow template: %w", err)
	}
	if err := decoder.Decode(&struct{}{}); !errors.Is(err, io.EOF) {
		if err == nil {
			err = errors.New("multiple JSON values")
		}
		return fmt.Errorf("decode trailing workflow template JSON: %w", err)
	}
	return nil
}
```

`requiredV1Alpha1Fields` 只解码 `map[string]json.RawMessage` 和 `[]json.RawMessage`，逐层调用 `requireObjectField`；它必须返回稳定排序路径，不读取 config 内部业务字段。

NodeCatalog 扩展 PackageFor；Analyzer 在 Compiler 成功后调用：

```go
func derivePackageRequirements(graph domain.Graph, catalog NodeCatalog) []NodePackageRequirement
```

只包含非 builtin source；development/replacement 省略 version。Analyze 成功后的 Normalized 总是使用本地派生提示，不保存输入提示。缺失节点时只用输入 hint 丰富现有 issue。

Canonicalize clone 两层包/节点切片并稳定排序，nil 规范为 []。
