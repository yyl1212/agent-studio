# Agent Studio v0.3-C 官方节点索引仓库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建 `yyl1212/agent-studio-node-index`，用只读 PR 校验、确定性生成和 GitHub 不可变 Release 发布官方节点包索引。

**Architecture:** 投稿文件把固定 GitHub commit、精选字段和已核验 NodePackage 清单副本一起提交；可信生成器把它们合并为单一 `index.json`。外部 PR 只作为数据输入，正式发布只读取索引仓库自身 Tag，不在发布阶段依赖第三方仓库。

**Tech Stack:** Go 1.26.5、`encoding/json`、`golang.org/x/mod`、`jsonschema/v6`、GitHub Actions、GitHub CLI、GitHub REST API 2026-03-10。

**Spec:** `docs/superpowers/specs/2026-08-20-v0.3-git-node-index-design.md`

## Global Constraints

- 本计划操作公开外部仓库；执行 Task 1 和 Task 7 前分别取得用户对“创建仓库”和“合并/公开 Release”的明确授权。
- 官方仓库固定为 `https://github.com/yyl1212/agent-studio-node-index`，不接受可配置替代源。
- Go 命令统一设置 `CGO_ENABLED=0`。
- 外部作者 PR 只能修改 `packages/`；可信 validator 来自默认分支，不执行 PR 分支代码。
- PR 验证只读取 GitHub API 上固定 commit 的 `go.mod` 与 `agent-studio.node-package.json`，不 checkout、编译或运行第三方代码。
- `index.json` 最大 4 MiB、最多 1,000 包、每包 20 版本、每版本 128 registrations/512 nodes。
- 远程 Release 必须是稳定 SemVer、非 draft、非 prerelease，并在发布后返回 `immutable=true`。
- Release 先建 draft、上传并复核全部资产，再公开；已发布 Tag 和资产不得复用或改写。
- 文档使用中文；所有 Action 固定到完整 commit SHA。
- 每个任务执行红灯、最小实现、绿灯、聚焦回归和独立提交。

```go
func ParseSubmission(source string, data []byte) (Submission, error) {
    if len(data) > MaxSubmissionBytes || !utf8.Valid(data) { return Submission{}, invalid(source, "invalid size or UTF-8") }
    if err := rejectDuplicateObjectKeys(data); err != nil { return Submission{}, invalid(source, err.Error()) }
    var wire submissionWire
    if err := decodeOneStrict(data, &wire); err != nil { return Submission{}, invalid(source, err.Error()) }
    value, err := wire.value()
    if err != nil { return Submission{}, invalid(source, err.Error()) }
    value = normalizeSubmission(value)
    if err := validateSubmission(value); err != nil { return Submission{}, invalid(source, err.Error()) }
    return value, nil
}
```

- [ ] **Step 3: Implement the fixed API sequence**

```go
func (v *GitHubVerifier) Verify(ctx context.Context, submission Submission) error {
    owner, repo, err := parseGitHubRepository(submission.Source.Repository)
    if err != nil { return err }
    commit, err := v.resolveTag(ctx, owner, repo, submission.Source.Tag)
    if err != nil { return err }
    if commit != submission.Source.Commit { return errors.New("source.tag does not resolve to source.commit") }
    manifestRaw, err := v.content(ctx, owner, repo, path.Join(submission.Source.ModuleDir, "agent-studio.node-package.json"), commit, 256<<10)
    if err != nil { return err }
    goModRaw, err := v.content(ctx, owner, repo, path.Join(submission.Source.ModuleDir, "go.mod"), commit, 1<<20)
    if err != nil { return err }
    return verifyPinnedFiles(submission, manifestRaw, goModRaw)
}
```

Verifier 复制而不修改传入的 `http.Client`，安装重定向策略并拒绝 HTTPS `api.github.com` 之外的所有目标，且只有精确核对该 host 后才添加 Authorization。`resolveTag` 最多跟随一个 annotated Tag 对象，并要求最终对象类型为 `commit`。`content` 必须用逐段转义且已验证的路径段构造 `/repos/{owner}/{repo}/contents/{path}?ref={commit}`，要求 base64 编码并限制解码字节数。`verifyPinnedFiles` 必须比较原始 SHA-256、严格解析 manifest、把规范化类型值与 `submission.Manifest` 逐字段比较、用 `modfile.Parse` 解析 go.mod、比较 module path，并调用 `module.CheckPathMajor`。

func Generate(input GenerateInput) (Index, error) {
    if !semver.IsValid(input.Release) || semver.Prerelease(input.Release) != "" { return Index{}, errors.New("release must be stable SemVer") }
