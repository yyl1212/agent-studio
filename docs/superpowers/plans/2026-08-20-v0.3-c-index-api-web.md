# Agent Studio v0.3-C 节点索引只读 API 与 Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 C2 Catalog 暴露为三个本地只读 GET API，并建设聚焦式单栏节点包目录页面。

**Architecture:** server 只注入 `NodePackageCatalog` 读接口；HTTP handler 做严格参数解析并返回安全 DTO，不持有 Refresher/GitHubSource。React 页面只调用本地 API，URL query 保存筛选状态，详情按需加载；页面没有刷新或安装动作。

**Tech Stack:** Go 1.26.5、chi v5、OpenAPI 3.1、React 19、TypeScript 5.9、React Router 7、Vitest 4、Testing Library、Playwright Chromium。

**Spec:** `docs/superpowers/specs/2026-08-20-v0.3-git-node-index-design.md`

## Global Constraints

- 开始前确认 C2 已合并，拉取最新 `origin/main` 并创建 `codex/v0.3-c-index-api-web` 隔离 worktree。
- Go 命令统一设置 `CGO_ENABLED=0`。
- API 只新增 `GET /api/node-index/status`、`GET /api/node-packages`、`GET /api/node-package?name=`。
- Router/handler/server 不得 import、构造或调用 `GitHubSource`、`Refresher`；不得新增 refresh/install POST。
- 索引故障不影响 `/readyz`；本地 cache 无效时 API 返回最后有效/embedded Snapshot 及 warning。
- Module path 详情使用 query 参数，不放入 path segment。
- 列表 limit 默认 50、最大 100，offset 最大 10,000，category 重复参数使用 OR。
- Web 只能调用以 `/api/` 开头的相对路径，不得访问 GitHub API 或写 cache。
- 页面保持聚焦式单栏；无安装、刷新、启用、信任、评分按钮。
- 第三方文本只按纯文本渲染，禁止 `dangerouslySetInnerHTML`；外链使用 `noopener noreferrer`。
- deprecated/withdrawn 提示不能只依赖颜色；空态区分 embedded 空索引、无匹配、无兼容包。
- OpenAPI 是前后端 DTO 权威；生成文件必须无漂移。
- 每个任务 TDD、独立提交；完成后代码审查、E2E 和全量回归。

```ts
listNodePackages: (query: NodePackageQuery, signal?: AbortSignal) => {
  const params = new URLSearchParams()
  if (query.q) params.set('q', query.q)
  for (const category of query.categories) params.append('category', category)
  params.set('compatible', String(query.compatible))
  params.set('limit', String(query.limit))
  params.set('offset', String(query.offset))
  return request<NodePackageSearchResult>(`/api/node-packages?${params}`, { signal })
},
getNodePackage: (name: string, signal?: AbortSignal) => {
  const params = new URLSearchParams({ name })
  return request<NodePackageDetail>(`/api/node-package?${params}`, { signal })
},
```
