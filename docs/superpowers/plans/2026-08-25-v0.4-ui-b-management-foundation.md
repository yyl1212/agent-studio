# Agent Studio v0.4-UI-B 管理台基础实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 UI-B 的第一个可独立合并 PR：工作流搜索与生命周期管理、全局 Run 游标查询、聚焦式只读详情工作台，以及归档工作流的全链路写入守卫。

**Architecture:** 在现有 React → Go Service → PostgreSQL 分层中新增不含图数据的 WorkflowSummary 和 RunSummary 分页资源。工作流管理使用独立 `WorkflowManagementService`，Run 只读管理使用独立 `RunManagementService`；现有执行引擎、Run 状态机和 NDJSON 流在本 PR 保持不变。

**Tech Stack:** Go 1.26、chi、pgx v5、PostgreSQL（Docker）、OpenAPI 3、React 19、React Router 7、TypeScript 5.9、Vitest、Testing Library、Playwright。

**Spec:** `docs/superpowers/specs/2026-08-25-v0.4-ui-b-management-design.md`

var ErrCursorInvalid = errors.New("management cursor invalid")

const managementCursorVersion = 1
const maxManagementCursorBytes = 512

func filterFingerprint(value any) string {
	encoded, err := json.Marshal(value)
	if err != nil {
		panic(fmt.Sprintf("encode cursor filter: %v", err))
	}
	digest := sha256.Sum256(encoded)
	return hex.EncodeToString(digest[:])
}
