# Agent Studio v0.4-A 节点调试与运行回放 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 持久化可刷新恢复的脱敏运行事件，在只读历史画布中回放节点状态，并从一个历史节点创建带冻结边和副作用确认的局部 debug 运行。

**Architecture:** 在公共 Go Node SDK 中增加保守默认的执行安全等级；PostgreSQL 追加保存全序事件，现有 `node_runs` 保留摘要职责。统一 Engine 通过可选 `ExecutionScope` 执行入口节点及其后代，Debug Service 从完整历史事件重建外部入边状态，HTTP/OpenAPI 暴露回放、预览和 NDJSON 重跑，React 使用只读画布与单一右侧调试工作台完成交互。

**Tech Stack:** Go 1.26.5、chi、pgx v5、PostgreSQL 18（Docker Compose）、OpenAPI 3.1、React 19、TypeScript 5.9、`@xyflow/react`、Vitest 4、Playwright 1.62、pnpm 10.34.5。

**Spec:** `docs/superpowers/specs/2026-08-25-v0.4-a-debug-replay-design.md`

## Global Constraints

- 执行前使用 `superpowers:using-git-worktrees`：拉取最新 `origin/main`，从包含规格和计划提交的基线创建隔离实现分支 `codex/v0.4-a-debug-replay`，不得直接在 `main` 开发。
- 所有 Go 调试、测试、vet、生成和运行命令必须使用 `CGO_ENABLED=0`。
- 严格 TDD：生产行为先得到真实 RED，再写最小实现得到 GREEN；每个任务结束时运行聚焦测试、`git diff --check` 并独立提交。
- 回放只读，不得调用任何节点；只有显式 POST 局部重跑可以进入 Engine。
- 局部重跑只执行入口节点及其全部后代；入口使用可编辑历史输入，外部进入活动子图的边只能使用完整、未脱敏的历史证据。
- `ExecutionSafety` 只允许 `pure | read_only | side_effect`；缺失、空值和未知值的有效等级必须为 `side_effect`，POST 必须服务端复算。
- `node.completed.activePorts` 必须显式编码为数组；非空时与 output key 取交集，空数组时全部 output key 激活。
- 事件数量上限为 `2 × 图节点数 + 2`；每个 input/output 各 1 MiB；公开 error 64 KiB；单 run 全部事件数据 16 MiB。
- 事件只保存脱敏值和不含原值的 JSON Pointer；不得增加明文、可逆加密或秘密恢复存储。
- 历史无 `run_events` 的运行只展示 `node_runs` 摘要，不伪造精确时间线，也不允许局部重跑。
- 不引入消息队列、独立 Worker、断线续跑、事件自动播放、任意子图、逐步执行或本地 RAG。
- `contracts/openapi.yaml` 是 HTTP 契约唯一来源；修改后运行生成命令，禁止手工编辑 `apps/web/src/lib/api/generated.ts`。
- 所有用户文档使用中文；不创建或修改 Tag、GitHub Release、不可变发布资产。
- 完成后必须经过代码审查和完整回归，Critical/Important 清零后才允许创建 PR。

type ExecutionSafety string

const (
    ExecutionSafetyPure       ExecutionSafety = "pure"
    ExecutionSafetyReadOnly   ExecutionSafety = "read_only"
    ExecutionSafetySideEffect ExecutionSafety = "side_effect"
)

func EffectiveExecutionSafety(value ExecutionSafety) ExecutionSafety {
    switch value {
    case ExecutionSafetyPure, ExecutionSafetyReadOnly, ExecutionSafetySideEffect:
        return value
    default:
        return ExecutionSafetySideEffect
    }
}

export async function connectIndexedPorts(
  page: Page,
  connections: Array<[string, number, string, string, number, string]>,
) {
  for (const [sourceType, sourceIndex, sourcePort, targetType, targetIndex, targetPort] of connections) {
    const sourceNode = page.getByTestId(`node-${sourceType}`).nth(sourceIndex).locator('..')
    const targetNode = page.getByTestId(`node-${targetType}`).nth(targetIndex).locator('..')
    await dragHandle(
      page,
      sourceNode.locator(`.react-flow__handle.source[data-port$=":${sourcePort}"]`),
      targetNode.locator(`.react-flow__handle.target[data-port$=":${targetPort}"]`),
    )
