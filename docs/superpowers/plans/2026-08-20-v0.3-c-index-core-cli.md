# Agent Studio v0.3-C 节点索引核心与 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Agent Studio 中实现严格索引解析、兼容推荐、离线 Store、GitHub 不可变 Release 显式刷新，以及 CLI status/refresh/search/info 闭环。

**Architecture:** `internal/nodeindex` 是唯一索引领域层：内置快照和本地 cache 进入同一个不可变 Snapshot，Catalog 统一推荐与查询，Refresher 是唯一联网写入口。CLI 组合这些接口；服务端在下一计划中只拿 Catalog，不接触 GitHub Client 或刷新方法。

**Tech Stack:** Go 1.26.5、`encoding/json`、`embed`、`net/http`、`golang.org/x/mod`、`golang.org/x/sys/unix`、GitHub REST API 2026-03-10。

**Spec:** `docs/superpowers/specs/2026-08-20-v0.3-git-node-index-design.md`

## Global Constraints

- 开始前拉取最新 `origin/main`，确认 C1 `v0.1.0` immutable Release 已公开，再创建 `codex/v0.3-c-index-core-cli` 隔离 worktree。
- Go 命令统一设置 `CGO_ENABLED=0`。
- 固定源 `yyl1212/agent-studio-node-index`；不得提供 URL/repo/token 覆盖参数。
- 产品不读取或发送 `GITHUB_TOKEN`、Git 凭据、Cookie 或 Authorization。
- cache 环境变量固定 `AGENT_STUDIO_NODE_INDEX_CACHE_DIR`；远程与本地缓存只有一个 `index.json`。
- 本计划只预留 API 的 cache-dir 配置，不实现 HTTP API/Web 功能；只有 CLI `node index refresh` 可以联网和写 cache。
- `index.json` 最大 4 MiB，严格拒绝未知字段、重复键、非法 UTF-8、尾随值和资源超限。
- 推荐版本必须是 approved + active + stable + Node API 精确匹配 + Runtime 半开区间兼容中的最高 Go SemVer。
- 刷新必须校验 Release full/stable/immutable、唯一资产、API digest、Schema/语义、metadata Release，并拒绝降级。
- 原子写使用同目录临时文件、0600、fsync、rename；完整刷新周期持有非阻塞 advisory lock。
- macOS/Linux 使用 `x/sys/unix.Flock`；其他平台明确返回 unsupported，不无锁降级。
- 不新增数据库迁移，不修改节点 Registry/Compiler/Runtime。
- 每个任务使用 TDD、聚焦回归、独立提交；完成前做代码审查和全量回归。

```go
func Recommend(pkg Package, runtime Runtime) Recommendation {
    current, err := normalizeRuntime(runtime.Version)
    if err != nil { return Recommendation{Reasons: []Reason{ReasonRuntimeInvalid}} }
    candidates := compatibleActiveStable(pkg.Versions, current, runtime.NodeAPI)
    slices.SortFunc(candidates, func(a, b PackageVersion) int { return semver.Compare(a.Version, b.Version) })
    if len(candidates) == 0 { return explainNoRecommendation(pkg, current, runtime.NodeAPI) }
    selected := cloneVersion(candidates[len(candidates)-1])
    return Recommendation{Version: &selected, Reasons: []Reason{}}
}
```

`normalizeRuntime` 只添加一次 `v` 前缀，并且只把精确内部形式 `x.y.z-dev` 映射到其稳定基线。不得把任意非法版本视为兼容。

```go
//go:build darwin || linux
func tryRefreshLock(cacheDir string) (func() error, error) {
    if err := os.MkdirAll(cacheDir, 0o700); err != nil { return nil, coded(CodeCacheWriteFailed, err) }
    file, err := os.OpenFile(filepath.Join(cacheDir, "refresh.lock"), os.O_CREATE|os.O_RDWR, 0o600)
    if err != nil { return nil, coded(CodeCacheWriteFailed, err) }
    if err := unix.Flock(int(file.Fd()), unix.LOCK_EX|unix.LOCK_NB); err != nil {
        file.Close()
        if errors.Is(err, unix.EWOULDBLOCK) { return nil, coded(CodeRefreshInProgress, err) }
        return nil, coded(CodeCacheWriteFailed, err)
    }
    return func() error { defer file.Close(); return unix.Flock(int(file.Fd()), unix.LOCK_UN) }, nil
}
```

把 `golang.org/x/sys v0.42.0` 移到 direct require block。只有 `refresh` 创建 cache 目录；Store/status 保持只读。不支持的平台返回 `INDEX_REFRESH_UNSUPPORTED`。

- [ ] **Step 4: Implement atomic write and refresh sequence**

`writeAtomic` 以 0700 创建目录，在同目录创建唯一 temp，chmod 0600，写完全部字节，执行 fsync、close、rename 到 `index.json`，再尽力同步目录；defer cleanup 只删除其精确 temp path。

`Refresh` 在联网前获取锁，加载 latest，下载并校验 digest，调用 `Parse`，要求 metadata release/tag 相等，并用 `semver.Compare` 与当前有效 Snapshot 比较。较低 Release 被拒绝。相同 Release 但有效字节不同时返回 `INDEX_RELEASE_INVALID`；相同、逐字节一致且无 warning 的 cache 才是 `already-current`。即使 Release 相同，embedded 或 warning 状态也要通过原子写入已验证远端字节完成修复。此前任一错误都不能改变 `index.json`。
