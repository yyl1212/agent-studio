# v0.5.0 GA 画布体验收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有画布事务上增加显式节点放置操作，并在节点配置区准确展示工作流保存状态。

**Architecture:** `StudioPage` 继续持有放置状态、节点创建回调和唯一 `SaveState`。新的 `NodePlacementActions` 只上报确认/取消；`NodeConfigPanel` 只读展示本地草稿状态与全局保存状态，保存仍通过现有 `SaveQueue`。

**Tech Stack:** React 19、TypeScript、React Flow、Vitest、Testing Library、Playwright、CSS。

**Spec:** `docs/superpowers/specs/2026-09-28-v0.5.0-ga-stabilization-design.md`

## Global Constraints

- 从执行当日最新 `origin/main` 创建新的 `codex/v0.5.0-ga-pr1-canvas-ux` 分支与隔离工作树；不得在旧设计分支上实现。
- 不修改 OpenAPI、Go API、PostgreSQL migration、SDK、节点 manifest、工作流 Graph 格式和公开节点的端口/错误语义。
- 复用 `StudioPage.confirmPlacement`、取消路径、`createAndCommitNode` 与唯一 `SaveQueue`，不增加新的保存通道或状态库。
- Runtime 开发构建 `0.5.0-dev`，SDK `0.5.0`，Node API `agent-studio.dev/v1alpha1`，官方 Runtime 范围 `[v0.2.0, v0.6.0)`。
- UI 文案和文档使用中文；桌面、768px、390px 无页面横向溢出，操作目标至少 44px，支持键盘、触屏与 reduced motion。
- 每条测试命令由执行器限制在 600 秒内；Go 调试与测试显式设置 `CGO_ENABLED=0`。

## Review Focus

1. 节点定义在预览期间失效：确认后不创建节点、不保存，并显示既有“节点定义已更新”错误；Task 2 测试。
2. 工作流在预览期间变成只读：显式确认不能绕过现有 `createAndCommitNode` 门禁；Task 2 测试。
3. 键盘确认与画布点击都可完成放置，但一次操作不能创建两个节点；Task 1、2 测试。
4. 配置草稿已应用而保存失败/冲突：配置区不能让用户误认为服务端已保存；Task 3 测试。
5. 有未应用草稿且工作流已保存：两个状态同时可见，不能把局部草稿误称为已保存；Task 3 测试。
