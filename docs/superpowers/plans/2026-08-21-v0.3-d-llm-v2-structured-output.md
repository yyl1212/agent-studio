# Agent Studio v0.3-D LLM v2 结构化输出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增保持 `llm@1` 完全兼容的 `llm@2`，通过低代码字段配置、OpenAI-compatible 原生 strict JSON Schema、本地二次校验和动态端口提供可靠结构化输出。

**Architecture:** `llm@2` 在内置节点层把受限字段配置确定性编译为 JSON Schema 和端口快照；内部 model provider 接收可选 `JSONSchemaFormat`，OpenAI-compatible 发送原生 `response_format`，Mock 从同一 Schema 生成确定性结果。节点对返回文本使用 `UseNumber` 严格解码并再次校验，公开错误只通过固定 allowlist 暴露安全信息。

**Tech Stack:** Go 1.26.5、`encoding/json`、`crypto/sha256`、`github.com/santhosh-tekuri/jsonschema/v6`、React 19、TypeScript 5.9、Vitest 4、Playwright 1.62、Docker PostgreSQL 18。

type llmV2FieldType string
const (

    llmV2FieldInteger llmV2FieldType = "integer"
    llmV2FieldBoolean llmV2FieldType = "boolean"

type llmV2Field struct {

    Label string `json:"label"`
    Description string `json:"description,omitempty"`

    Required *bool `json:"required,omitempty"`

- [ ] **Step 5: 实现严格 JSON 解码和本地 Schema 校验**

实现签名：

```go
func decodeLLMV2StructuredOutput(raw string, schemaJSON json.RawMessage) (map[string]any, error)
```

定义 `const maxLLMV2StructuredOutputBytes = 1 << 20`，在分配解码对象前先以 `len(raw)` 检查字节预算，超限返回同一安全 sentinel。核心解码必须为：

```go
decoder := json.NewDecoder(strings.NewReader(raw))
decoder.UseNumber()
var value any
if err := decoder.Decode(&value); err != nil { return nil, ErrLLMV2OutputInvalid }
var trailing any
if err := decoder.Decode(&trailing); !errors.Is(err, io.EOF) { return nil, ErrLLMV2OutputInvalid }
object, ok := value.(map[string]any)
if !ok { return nil, ErrLLMV2OutputInvalid }
```

随后用以下固定资源名编译同一 Schema，再校验对象：

```go
const resource = "urn:agent-studio:llm-v2-output"
document, err := jsonschema.UnmarshalJSON(bytes.NewReader(schemaJSON))
if err != nil { return nil, ErrLLMV2OutputInvalid }
compiler := jsonschema.NewCompiler()
if err := compiler.AddResource(resource, document); err != nil { return nil, ErrLLMV2OutputInvalid }
schema, err := compiler.Compile(resource)
if err != nil { return nil, ErrLLMV2OutputInvalid }
if err := schema.Validate(object); err != nil { return nil, ErrLLMV2OutputInvalid }
```

所有错误只返回或包装 sentinel，不包含 raw 内容、Schema 内容或校验器生成的值片段。
