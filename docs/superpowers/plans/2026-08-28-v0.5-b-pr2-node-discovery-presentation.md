# v0.5-B PR2 节点发现与呈现 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把节点发现、点击放置、拖放和连线末端添加统一成一条可预览、可取消、只保存一次的创建链路，并建立专业一致的节点视觉语言。

**Architecture:** `nodeLibraryModel` 负责边界过滤、搜索和端口兼容判断；`WorkflowCanvas` 只将鼠标/触摸事件转换为画布坐标并显示 `ViewportPortal` 幽灵预览；`StudioPage` 持有放置和连接上下文并执行唯一的节点创建事务。`GenericNode` 与节点库卡片共享自制 `NodeIcon` 和同一组状态语义，不修改节点定义契约。

**Tech Stack:** React 19、TypeScript、React Flow 12.11.2、Vitest 4.1.10、Testing Library、Playwright、现有 CSS Token。

**Spec:** `docs/superpowers/specs/2026-08-28-v0.5-b-canvas-ux-design.md`

export function isAddableDefinition(definition: NodeDefinition) {
  return definition.type !== 'start' && definition.type !== 'end'
}

export function compatibleInputPorts(definition: NodeDefinition, sourceType: PortDataType) {
  return definition.inputs.filter((input) =>

  )
}
